Forgon Engine does not vendor T3 Code source. It consumes a pinned, separately installed
"t3" sidecar process over T3's published, versioned HTTP/WebSocket protocol, and re-derives
protocol constants and JSON shapes from the audited source above. The notice below is
retained because the Forgon bridge and sidecar manager adapt that protocol and copy the
MIT-licensed protocol constants and license text.

What was copied verbatim from upstream (all MIT, covered by the notice below):
- Protocol constants (ORCHESTRATION_PROTOCOL_VERSION, query param/header names, WS ticket
  query param) from packages/contracts/src/environment.ts and apps/server/src/auth/EnvironmentAuth.ts.
- Path strings and method names from packages/contracts/src/{environmentHttp,rpc,orchestrationV2}.ts.
- The shared-workspace restore refusal message from
  apps/server/src/orchestration-v2/CheckpointRestoreSafety.ts.
- Value unions (RuntimeMode, ProviderApprovalDecision, run/item status) from
  packages/contracts/src/{providerPolicy,orchestrationV2}.ts.

Third-party notices that are NOT settled by this file (see docs/research/agent-implementation.md
"Licensing" and docs/research/t3-reuse.md section 11):
