# Original placeholder assets
Author: Nitish

All Rooftop Relay geometry is authored as original primitives in the five course scenes. The relay ferry prefab, the wordmark SVG, the palette and both WAV cues were created for this repository, with no imported third-party artwork, audio or level data. These assets are dedicated under CC0-1.0 (https://creativecommons.org/publicdomain/zero/1.0/). The SVG uses a platform sans-serif font; no font file is distributed. Registry entries identify provenance. Assets are source documents: the runtime renders inline primitive colours and synthesized audio only, and does not claim texture import support.
